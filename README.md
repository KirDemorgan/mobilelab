# Задание 1 — карта и изображения

Приложение на Expo SDK 57, React Native и TypeScript. Настроено для iOS, как и исходная заготовка.

## Запуск

Нужны Node.js 22.13+ (LTS) и Expo Go с поддержкой SDK 57 на iPhone.

```sh
npm install
npm start
```

Подключите компьютер и телефон к одной сети и откройте QR-код камерой iPhone. Для симулятора iOS на macOS: `npm run ios`.

Проверка типов: `npm run typecheck`.

## Использование

1. Удерживайте точку на карте, чтобы добавить маркер.
2. Нажмите на маркер: откроются его координаты и изображения.
3. Нажмите «Добавить изображение» и выберите фотографию в системной галерее.
4. Кнопка под изображением удаляет его из списка этого маркера.
5. Вернитесь на карту стандартной кнопкой назад в заголовке.

## Реализация

- `src/app/index.tsx` — карта, добавление маркеров и переход к деталям.
- `src/app/marker/[id].tsx` — координаты и список фотографий, выбор через expo-image-picker.
- `src/app/_layout.tsx` — стек экранов Expo Router и общий провайдер данных.
- `src/context/markers-context.tsx` — React Context и useState для маркеров и изображений.
- `src/components/image-item.tsx` — изображение, ошибка загрузки и кнопка удаления.
- `src/types.ts` — интерфейсы маркера, изображения и параметров маршрута.

Дополнительных функций нет.

## Ограничения

- Данные хранятся только в памяти и сбрасываются при перезапуске. Удаление изображения из списка не удаляет оригинал из галереи.
- Для карты нужен интернет. Если компонент не готов через 15 секунд, появляется сообщение с повторной попыткой. onMapReady не гарантирует загрузку всех тайлов; универсального события ошибки загрузки тайлов у библиотеки нет.
- Используется стандартная Apple Maps на iOS; для Expo Go API-ключ не нужен.

## Проверка на iPhone

1. Создать два маркера и проверить координаты каждого.
2. Добавить несколько фотографий к первому маркеру; у второго список должен остаться пустым.
3. Отменить выбор фотографии и проверить, что список не изменился.
4. Удалить одну фотографию, вернуться на карту и снова открыть маркер.
5. Открыть несуществующий маршрут или ID: должно появиться сообщение с возвратом на карту.
6. Проверить запуск без интернета и повторную загрузку карты.
